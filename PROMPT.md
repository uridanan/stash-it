I read a lot of articles from all around the internet. I find them mostly on mobile but also on destkop. Many of them come from the news feed in my google app. Most of the time, I don't have the time to read the article on the spot, I need to save it for later. What I have in mind is similar to the apps getpocket (no longer exists) or instapaper. Start by creating a clone of instapaper.com, dockerized and ready to deploy via GCP cloudbuild. Don't forget a chrome extension to bookmark or save articles and a mobile app since most of the articles will be saved from my mobile phone and read on my mobile phone (I have an Android phone). Methodology

  

- Use Workflows and distribute the work between parallel subagents as much as possible
    
- Before starting to work, create a PLAN.md file you can refer to in order to remember what you were doing if the session gets interrupted
    
- Also create a PROGRESS.md file listing all the tasks you need to accomplish, update it with your progress so you can refer to it to remember the last task that you completed and where to continue from.
    
- You are done when all the tasks in PROGRESS.md are complete. That should include testing the desktop app and the chrome extension.
    

  

*Grill me before you get started in order to dispel any uncertainties you might have.
